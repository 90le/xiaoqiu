# 小丘 v2 · Phase 1-2 作战计划

> 制定：2026-09-14 · 原则：**规划先行，逐项验收**（用户指示）
> 前置：对话链路已通（智谱 Coding/API 双模板）+ CI 云编译 + 固定签名

---

## 总原则

1. **壳保留，魂移植**：OpenMinis 的权限/沙箱/稳定性壳不动，v1 的交互与功能设计为纲
2. **每项有验收**：不写完就算，装机实测通过才算
3. **v1 是设计圣经**：终端/对话/快捷菜单/语音的交互形态，以 v1 已验证的设计为准
4. 一次一个战役：不并行开多个半成品

---

## 战役清单（按序执行）

### 战役 A：语音可用（最快见效）
**目标**：App 内按住/点击说话 → 智谱 ASR 转写 → 回答 → cogtts 朗读

| 步骤 | 内容 | 验收 |
|---|---|---|
| A1 | 语音供应商添加智谱（已完成模板）| 设置→语音提供商列表见"智谱语音" |
| A2 | 录音权限引导 + 引擎选择 | 录音不崩，引擎显示选中 |
| A3 | ASR 实测：说中文→文字进输入框 | 转写延迟 <2s，中文准确 |
| A4 | TTS 实测：回答朗读（cogtts 童童）| 播报自然，可打断 |
| A5 | 长文流式 TTS（>400 字句级分段）| 首句 3s 内出声（v1 算法移植）|

**现状勘察**：v2 已有 SpeechRecognitionManager（引擎管理+VAD+分段+纠错学习骨架）、TextToSpeechManager、ReadAloudPlayer。缺：智谱引擎实测调通、长文流式。

### 战役 B：终端多标签（v1 设计移植）
**目标**：v1 终端完全体——会话列表+长按菜单+新建/切换/重命名/关闭

| 步骤 | 内容 | 验收 |
|---|---|---|
| B1 | 终端页顶部标签栏（横滑切换+新建+） | ✅ 多会话并存 |
| B2 | 长按标签菜单：重命名/重启/关闭 | ✅ 内联重命名+回车确认 |
| B3 | 标签状态点（活绿/死灰） | ✅ 死会话长按可重启 |
| B4 | 滚动+悬浮回底+惯性（v1 体验） | 流畅跟手 |
| B5 | 快捷键工具条（Ctrl/Esc/Tab/方向键等，v1 职责分离设计）| 组合键准确 |

**已完成（09-14 装机验证）**：TerminalSessionManager（Application 级会话池，输出泵常驻=切走不丢输出）+ TerminalTabsBar（横滚/状态点/长按菜单/＋）+ 离开终端页会话不杀（v1 语义）。B4/B5（滚动惯性/快捷键条增强）待用户实测反馈后补。

### 战役 C：快捷菜单（v1 设计移植）
**目标**：对话页输入区上方快捷短语条 + 命令面板

| 步骤 | 内容 | 验收 |
|---|---|---|
| C1 | 快捷短语横滚条（继续/总结/检查结果/换模型…） | 一键发送 |
| C2 | 短语管理（内置+自定义+长按删） | 可增删 |
| C3 | `/` 命令面板（斜杠命令：模型/思考/清屏/宏…） | 输入 / 弹面板 |
| C4 | 与 v2 现有 SlashExt 对齐（ChatViewModelSlashExt 已有基础）| 不重复造轮子 |

**现状勘察**：v2 已有 ChatViewModelSlashExt（斜杠命令基础）、ChatComposerWidgets（工具条）。缺 UI 层的短语条与面板。

### 战役 D：对话体验对齐 v1
**目标**：v1 对话页的交互细节全量补齐

| 步骤 | 内容 | 验收 |
|---|---|---|
| D1 | 消息编辑重发（退回编辑） | 长按消息可编辑 |
| D2 | ↻ 重试按钮 + 换模型重试 | 一键重试 |
| D3 | 附件：多选图片/拍照/文件 | 发送可读 |
| D4 | 思考档选择器（7 档，模型能力感知） | 灰显无效档 |
| D5 | 停止/中断按钮 | 流式中可停 |

**现状勘察**：v2 ChatViewModel 12383 行已含大部分逻辑（思考档/编辑/中断），主要是 UI 入口与交互细节对齐。

### 战役 E：中文界面
| 步骤 | 内容 | 验收 |
|---|---|---|
| E1 | i18n 机制接入（values-zh 或直接中文默认） | 全 UI 中文 |
| E2 | Onboarding 五步中文（复用 v2 已有 onboarding） | 引导流畅 |

### 战役 F：KWS 唤醒 + 快脑（v1 语音完全体）
**目标**：喊"小丘"全屏唤醒→说话→快脑直答/慢脑执行→播报（v1 完整体验）

| 步骤 | 内容 | 验收 |
|---|---|---|
| F1 | sherpa-onnx KWS 集成（模型从 v1 APK assets 迁移）| 喊小丘 300ms 内响应 |
| F2 | 前台常驻服务（AgentForegroundService 复用）| 锁屏可唤醒 |
| F3 | 声纹门禁（eres2net 模型+0.60 阈值）| 他人不唤醒 |
| F4 | 快脑分流（闲聊 flash 直答/任务主脑执行）| 闲聊 <3s |
| F5 | 连续对话循环（6s 静默收尾+打断）| 可连续多轮 |
| F6 | 唤醒全屏特效（四色流光+状态药丸，v1 视觉） | 视觉一致 |

**依赖**：战役 A 先通（TTS/ASR 管线复用）。
