# 小丘 (XiaoQiu)

**你的随身 AI 工作台。**

基于 OpenMinis 优秀架构重新设计的 Android AI Agent。

## 特性

- 🔥 **语音对话**：KWS 流式唤醒 + 声纹门禁 + 快脑直答 + 句级流式 TTS
- 💻 **终端**：完整 Linux 沙箱（PRoot + Alpine）
- 📱 **手机集成**：截屏·操作App·读通知·系统控制
- 🧠 **记忆系统**：自动沉淀 + 核心注入 + 透明时间线
- ⚡ **宏系统**：会话提取 + 参数化 + 进度播报
- 🦯 **无障碍操控**：隐形副屏 + 悬浮球
- 🎭 **人格系统**：SOUL.md 可编辑（参考 OpenMinis SoulStore）
- 🛡 **安全**：操作确认门控 + 工具死循环检测
